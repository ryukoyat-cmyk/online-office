# 온라인 교무실

전주초등학교 교직원을 위한 단일 페이지 런처. HTML, CSS, Vanilla JavaScript로 구현합니다.

## 실행

`python -m http.server 8080` 실행 후 http://localhost:8080 에 접속합니다. HTML을 직접 열어도 검색과 업무 링크는 사용할 수 있지만 식단 JSON은 HTTP 서버가 필요합니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소의 `main` 브랜치에 올립니다. `.github/workflows/update-meal.yml`도 포함합니다.
2. Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
3. Actions → Update meal and deploy Pages → Run workflow를 실행합니다.
4. 성공한 실행의 배포 URL에서 확인합니다.

매일 한국 시간 05:30에 급식을 조회하고 사이트를 다시 배포합니다. GitHub 예약 실행은 지연될 수 있습니다. 수동 실행도 가능합니다.

## 급식

공식 NEIS API에서 확인한 전주초등학교 코드: 교육청 `P10`, 학교 `8332185`. 중식만 조회합니다. 서버에서 한국 날짜를 사용하며 알레르기 번호를 제거합니다.

NEIS의 키 없는 호출로 먼저 동작합니다. 인증키를 사용할 경우 Settings → Secrets and variables → Actions에 `NEIS_API_KEY`를 추가합니다. 키는 서버에서만 사용하며 브라우저나 JSON에 포함하지 않습니다. 인증 없는 서비스의 제한이 바뀌면 키 설정이 필요할 수 있습니다.

조회 실패와 급식 없음은 구분합니다. 날짜가 지난 JSON을 오늘의 식단으로 표시하지 않습니다. 실패 시 오류 상태를 배포하고 Actions 실행을 실패로 보고합니다. 배포된 JSON은 Actions가 생성하므로 저장소의 초기 JSON과 달라질 수 있습니다.

## 화면 구성과 날씨·미세먼지 안내

데스크톱에서는 제목(좌) · Google 검색(우) → 날짜와 D-day(제목 아래) → 날씨·미세먼지 한 줄 상태 바 → 식단과 업무 카드 5개 순서입니다. 남는 세로 공간은 콘텐츠 위쪽 2 : 아래쪽 3 비율로 나누며, 카드 높이는 화면 높이에 맞춰 조절됩니다. 1366×768에서 스크롤 없이 한 화면에 표시하는 것을 기준으로 합니다. 767px 이하에서는 검색·상태 바·전북 업무포털을 숨기고 날씨와 미세먼지 요청 및 타이머를 중단합니다. 폰트는 Google Fonts의 Noto Sans KR이며, 불러오지 못하면 맑은 고딕 등 시스템 폰트로 표시합니다.

상태 바에는 날씨(기온·상태·최저/최고)와 미세먼지·초미세먼지 수치와 등급, 측정소·기준 시각이 표시됩니다. 실외 활동 안내는 별도 카드 없이, 두 항목 중 더 나쁜 등급이 나쁨 이상이거나 공식 주의보·경보가 활성일 때만 상태 바에 경고 칩(예: 실외 활동 자제, 실외수업 금지 안내)으로 나타납니다.

### 에어코리아 설정

공공데이터포털에서 아래 **두 서비스 모두** 활용 신청 후, 저장소 Settings → Secrets and variables → Actions에 `AIRKOREA_API_KEY`를 등록하세요. 일반 인증키(Decoding)를 권장하며 Encoding 키도 처리합니다. 인증키는 브라우저·JSON·로그에 포함하지 않습니다.

- [대기오염정보](https://www.data.go.kr/data/15073861/openapi.do): 측정소별 실시간 관측값
- [미세먼지 경보 발령 현황](https://www.data.go.kr/data/15073885/openapi.do): 공식 발령과 해제 시각

측정소는 전주시 완산구 삼천동(용리로 107 삼천도서관 옥상)입니다. [에어코리아 측정소 목록](https://www.airkorea.or.kr/web/stationInfo)에서 PM10·PM2.5 측정항목을 확인했습니다. 학교 운동장 자체 측정값이 아니며 측정소명과 시각을 표시합니다. 경보는 전주·익산·완주가 포함된 **전북 중부권**을 적용합니다([전북도 권역 안내](https://www.jeonbuk.go.kr/newsroom/board/view.jeonbuk?boardId=BBS_0000090&dataSid=651938&menuCd=DOM_000001101000000000)).

기존 매일 05:30 갱신 외에 평일 KST 07:15~17:15 매시간 날씨·미세먼지를 수집하고 Pages를 배포합니다. GitHub 예약 실행은 지연될 수 있습니다. 각 실행에서 급식·D-day도 다시 생성하므로 시간별 배포에 당일 자료가 포함됩니다. 브라우저는 화면 진입·복귀 및 10분 간격으로 JSON을 읽고 매분 자료 유효성을 다시 판단합니다.

`data/air-quality.json`은 `status`, `station`, `source`, `updatedAt`, `measuredAt`(시간대 포함 ISO 8601), `pm10`, `pm25`, `alerts`를 제공합니다. `alerts`에는 `status`, `checkedAt`, `active` 목록이 있으며 각 경보에는 `pollutant`, `level`, `issuedAt`이 포함됩니다. 값 누락은 `null`로 기록합니다. `weather.json`에는 관측 시각 `observedAt`을 추가했습니다.

### 안내 기준과 한계

PM10 등급은 30/80/150, PM2.5 등급은 15/35/75를 상한으로 구분합니다. 두 항목 중 더 나쁜 상태가 나쁨 이상이면 경고 칩으로 실외 활동 자제·실내 활동 전환 권고를 표시합니다. 매우 나쁨 등급을 주의보로 추정하지 않습니다. 공식 중부권 주의보·경보가 활성 상태이면 실외수업 금지를 안내합니다. 연말부터 이어진 경보와 모든 조회 페이지를 처리합니다.

[교육청 공개 대응체계](https://use.go.kr/edusafe/infect/dust.jsp)의 나쁨 단계 실외수업 자제 및 주의보·경보 단계 실외수업 금지 안내를 참고했습니다(확인일 2026-10-10). 이는 전북교육청의 최신 문서를 확인했다는 의미가 아닙니다. 학교별 대응 지침과 최종 판단이 우선하며, 비·눈·폭염 등은 판단에 포함하지 않습니다.

측정값 또는 경보 조회 시각이 2시간 이상 오래됐거나 필요한 정보가 누락되면 등급 자리에 ‘확인 필요’를 표시하고 경고 칩은 띄우지 않습니다. 초기 JSON·인증키 미설정·조회 실패에도 같습니다. 수집 실패는 오류 JSON을 배포한 뒤 Actions 실패로 보고합니다. 마지막 예전 관측값을 정상 자료로 승격하지 않습니다.

### 검증

`python scripts/test_air_quality.py`, `node scripts/test_environment.cjs`로 값·측정기 점검·자정·페이지 누락·경보 발령과 해제·자료 유효성 경계를 검증합니다. 실제 API 응답 검증은 인증키 설정 후 Actions 수동 실행으로 진행하고, 화면의 측정소·시각·값 및 중부권 경보 상태를 에어코리아와 대조하세요.

## D-day

표시할 일정은 `data/dday-source.json`에 `label`, `date`(YYYY-MM-DD)로 적습니다. 현재는 올해 겨울방학(2026-12-30)만 등록되어 있습니다. 일정 날짜가 지나면 D-day는 자동으로 사라지며, 별도 정리나 수정이 필요 없습니다. 내년에도 쓰려면 새 일정을 이 파일에 추가하면 됩니다.

## 링크와 디자인 수정

업무 링크는 `js/config.js`, 디자인은 `css/style.css`에서 수정합니다. JavaScript 비활성 환경용 링크도 변경하려면 `index.html`의 href를 함께 수정합니다.

검색어·계정·방문 기록을 사이트에서 저장하지 않습니다. Google 검색 및 업무 자료는 새 탭에서 열립니다. Google 자료의 열람 권한은 원본 서비스에서 관리합니다.
